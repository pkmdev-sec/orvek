# Bundled 8x13 font

`8x13-ascii.bin` contains the 95 printable ASCII glyphs (U+0020 through
U+007E) from the Xorg Misc Fixed 8x13 bitmap font. Each glyph has 13 bytes,
one byte per row from top to bottom. The most significant bit is the left
pixel; a set bit represents black ink. The renderer places these unchanged
8x13 glyphs on an 8x16 grid.

The source is [`crates/pi-natives/src/fonts/8x13.bdf` in oh-my-pi](https://github.com/can1357/oh-my-pi/blob/e109c5a63fc1ef67e8543094be45494de1252cf4/crates/pi-natives/src/fonts/8x13.bdf),
pinned to commit `e109c5a63fc1ef67e8543094be45494de1252cf4`. Its font name is
`-Misc-Fixed-Medium-R-Normal--13-120-75-75-C-80-ISO10646-1`, and its revision
comment is `$ucs-fonts: 8x13.bdf,v 1.57 2006-01-05 20:24:11+00 mgk25 Rel $`.
The original font's copyright declaration is retained in [LICENSE](LICENSE).

Source SHA-256:
`c39b53bd625f35e6681d5097d81e6bf81b44a9f6730068c4c8f4716d779fd40e`.

Run `python3 bin/orvek/src/core/compaction/fonts/generate.py` from the repository
root to download the pinned source, verify its hash, and regenerate the subset.
Use `--source /path/to/8x13.bdf` to regenerate from a local copy instead.
The application bundles the generated bytes and never downloads a font at runtime.
