Type to filter; Enter/Tab inspects. Ctrl+S sorts; Ctrl+N changes remote scope; Ctrl+R refreshes. Ctrl+D or Delete requests removal; a second physical D/Delete confirms. In details, R refreshes and D requests removal. Esc goes back or closes. Use the result controls to finish a simulated operation. No real memory is read, changed, or deleted.






Keep filtering readable
The filter has its own row. Source, sort, and namespace scope stay separate. Each memory keeps a compact preview and a quieter identity line.


Content before metadata
Inspect opens the complete text first. Version, timestamps, scan/use counts, and probation follow below. Browsing does not count as an agent using a memory.


Remove the exact record
Confirmation shows the namespace, ID, and version. Remote readers cannot delete; writers can delete only their own namespace. A changed record reloads for another review.
