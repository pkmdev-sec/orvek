Arrows select. Shift+arrows reorder queued items. E edits; D deletes; Enter steers; Esc returns focus. Pending and retained items cannot be edited, deleted, or steered again. All events are manual samples; nothing is sent to an agent.






Keep the existing stack

Accepted is not applied
